# Mathematical Operations

**Summary**: SVO encodes mathematical operations as transformations that turn one quantity into a new quantity with modified units, serialized using "of" as a delimiter.

**Sources**: Peckham_and_Stoica_2022_ICWRER_2022.pdf

**Last updated**: 2026-06-06

---

Many quantities used by geoscientists are generated by applying a mathematical (or other) operation to an existing quantity to create a new quantity. In English we almost always insert the verbal delimiter **"of"** after these operations, and they can be chained together — so serialized [[scientific-variables-ontology|SVO]] variable names use "of" as the delimiter for operations (source: Peckham_and_Stoica_2022_ICWRER_2022.pdf).

Including operations is a distinctive feature of SVO: it is described as the only variable-description system the authors know of that also includes most mathematical operations, recognizing that applying an operation simply produces a new quantity with modified units (source: Peckham_and_Stoica_2022_ICWRER_2022.pdf).

## Common operations

Some operations apply only to a specific **field type** (scalar, vector, or tensor) (source: Peckham_and_Stoica_2022_ICWRER_2022.pdf):

| Operation | Change to units U | Applies to | Returns |
|---|---|---|---|
| time_derivative_of | U T⁻¹ | any (component-wise) | same |
| area_integral_of | U L² | scalar | scalar |
| log_of | log(U) | scalar | scalar |
| x_component_of | U | vector | scalar |
| x_y_component_of | U | tensor | scalar |
| azimuth_angle_of | radians | vector | scalar |
| zenith_angle_of | radians | vector | scalar |
| divergence_of | U L⁻¹ | vector | scalar |
| gradient_of | U L⁻¹ | scalar | vector |
| curl_of | U L⁻¹ | vector | vector |
| laplacian_of | U L⁻² | scalar | scalar |

These come from the [[csdms-standard-names]] and SVO collections. Operations interact with the dimension system of the [[international-system-of-quantities]] and with the schema in [[fluxes-and-flow-rates]] (e.g., divergence_of_X_flux).
